# Severe flooding and cause-specific hospitalization among older adults in the United States 

Paper: 

## Overview

This repository contains R scripts for processing and analyzing flood exposure data to study mechanisms for cause-specific hospitalization in Medicare enrollees from 2000-2016 in the contiguous United States. Code for visualizations included in the main manuscript is also included.
